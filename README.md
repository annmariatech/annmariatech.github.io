# Ann Maria — portfolio

A pastel terminal inspired portfolio for Ann Maria, an Information Technology student at the School of Engineering, CUSAT. It brings together selected projects, experience, skills, music, and contact links in one responsive page.

## Contents

- `index.html` — page content and structure
- `style.css` — layout, pastel terminal styling, and light/dark themes
- `script.js` — interactions, including project screenshot previews, theme switching, and the mini terminal
- `assets/` — images and other portfolio assets

## Run locally

This is a static site with no build step or package installation required. Open `index.html` in a browser, or serve the repository with any local static file server. For example:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy

The site is published from this GitHub repository using GitHub Pages.
